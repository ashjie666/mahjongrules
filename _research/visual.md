# 视觉基因 visual.md

> 站点视觉必须与主题同源。麻将没有单一官方站点，视觉取自**牌具本体**，并用线上麻将 UI 做二次校验。

| 项 | 内容 |
|---|---|
| 参考页 | Mahjong Soul 官网（https://mahjongsoul.yostarjp.com/，UI 参考）；牌具本体（象牙牌面 + 竹背 + 朱红「中」） |
| 取色来源 | 牌具本体采样 + 线上 UI 观察；取色日期 2026-10-30 |
| 色板（浅色） | 纸面底 `#f6f1e6`；面板 `#fffdf7`；墨色 `#1c1a17`；主强调（朱红）`#b03a2e`；竹青 `#2f6b4f`；金 `#c19a4b`；靛 `#22384a` |
| 色板（深色） | 毡绿底 `#101d18`；面板 `#182822`；墨色反转 `#f1ece1`；强调 `#e2674f`；竹青 `#62a882`；金 `#d8b263` |
| 造型语言 | 牌面的圆角矩形 + 象牙底 + 硬投影；竹背竖纹用 repeating-linear-gradient；牌角金线内框；贴纸式标签（小圆角、粗描边） |
| 字体方向 | 标题：衬线展示体（Georgia / Palatino 系统栈，严肃参考书气质）；正文：系统无衬线（Segoe UI / system-ui） |
| 可借用元素 | 牌形卡片、牌背纹理条、麻将牌九宫格式图标、算番表用牌面小方块 |
| 禁用元素 | 赌场绿+金色通用模板、扑克牌元素、第三方截图、emoji |

## 落地约定

- 单文件 `styles.css`，CSS 变量管理主题，`data-theme` 明暗切换
- 装饰全部 CSS 渐变 + 内联 SVG，不引第三方图片
- 页内信息图统一原创 SVG，820×340 画布，存 `web/images/*.svg`
- 每页最多 1 张图，放在导语首段之后、第一个 h2 之前
- favicon 内联 SVG（朱红牌面 + 白色圆环）
