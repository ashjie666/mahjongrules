# 竞品页面结构

> 只记录结构，不抄内容。用于找 H2 缺口与差异化切口。

## 1. Wikipedia — "Mahjong"
- H2：History / Equipment / Gameplay / Rules / Scoring / Variants / National/regional styles / Unicode
- 长度：长文，偏百科，无新手路径
- 有表格；无计算器
- 未回答：初学者该选哪种规则；8 番门槛实操；血战到底的结算
- 切口：把「选规则」前置成一页，而不是埋在 Variants 里

## 2. wikiHow — "How to Play Mahjong"
- H2：Setting up / Learning the pieces / Playing the game / Completing a hand / Scoring / Strategies
- 长度：中长，图文步骤
- 未回答：不同规则族的差异；计分只是笼统带过
- 切口：一页把 6 种主流规则的口径做成对照表

## 3. Mahjong Soul 官方站 / 日式规则页
- H2：基本ルール / 役 / 点数計算 / 振听
- 未回答：英文读者要的术语对照；与国标/美式的差异
- 切口：日式页补「英文术语 + 常见误判」

## 4. Riichi Wiki
- H2：Yaku / Scoring / Furiten / Defense / Tile efficiency
- 深度最好，但门槛高、无入门路径，偏日式单族
- 未回答：非日式读者如何迁移概念
- 切口：防守与牌效页用「通用原则 + 日式实现」的写法

## 5. Mahjongg Solitaire 类站点（搜索词竞争）
- 大量 "mahjong" 搜索结果实际是接龙消除游戏
- 未回答：两者关系；新手点进来发现玩错游戏
- 切口：做一页边界说明页，接住误搜索流量并导回真麻将

## 共性缺口（本站差异化）
1. 没有一页把「起和门槛」按 8 番 / 3 番 / 5 台 / 无门槛 / 年卡 讲清
2. 没有把「吃碰杠能不能用」做成逐规则矩阵
3. 地方玩法（川麻、广东、贵阳）英文资料极少且互相矛盾
4. 计分只讲一种规则，缺少 fan / fu / tai / point 的单位换算说明
